# Setup Center 开发端 · 使用说明

这个文件夹里的东西**只给你自己用**，不要发给别人。

---

## 里面有什么

| 文件 | 干什么 |
|---|---|
| `查码.exe` | **最常用**。双击 → 输入编号 → 看到明文激活码 |
| `issue.exe` | 生成新的激活码 |
| `license_admin.exe` | 查台账、记账、验证某个码是不是真的 |
| `license_inventory.csv` | 台账。哪个码发了、发了给谁、激活没有，都记在这 |
| `使用说明.md` | 就是你正在看的这个 |

---

## 每天最常做的三件事

### 1. 有人要一个码

双击 **`查码.exe`**，输入框里打编号，比如 `137`，回车。

会看到：

```
  编号      137
  类型      pro
  状态      未使用
  明文码    SC-ABCDE-23456-FGHJK-VWXYZ
```

把 `SC-ABCDE-23456-FGHJK-VWXYZ` 这串发给对方。**只发这一串**，前后文字不要带。

### 2. 记一下"这个码给谁了"

双击 **`license_admin.exe`** —— 但它会一闪就关。用下面的"记账"方式。

> **说明**：`license_admin.exe` 是命令行程序，双击会闪退。要记账请用 `记账.bat`（同一个文件夹里），双击它，按提示粘贴编号。

### 3. 看看总共发了多少、还剩多少

双击 **`查码.exe`**，**什么都不输，直接回车**。

就会列出全部 500 条，开头是统计：

```
  已发出未使用 : 372
  已激活       : 128
  已作废       : 0
  合计         : 500
```

## 生成新的激活码

以后要加新码（比如再做 200 个），双击 **`生成新码.bat`**，输入数量和类型。

或者在这个文件夹打开 PowerShell：

```
.\issue.exe 200 pro     生成 200 个专业版码
.\issue.exe 100 free    生成 100 个免费版码
```

生成后会自动追加到台账，**旧记录不会被动**。

---

## 记账（记录码的去向）

```
.\license_admin.exe list                        看全部
.\license_admin.exe status                      只看统计
.\license_admin.exe verify SC-XXX-...           验证一个码真不真
.\license_admin.exe mark 137 activated --note 张三       记：137 已激活，给张三
.\license_admin.exe mark 137 unused                     记：137 退回未使用
.\license_admin.exe mark 137 revoked                    记：137 作废
```

`mark` 之前会自动备份台账为 `.bak`，改坏了能用备份还原。

## 明文码存在哪

明文码**不在**这个文件夹里（这样整个文件夹拷给别人也不会泄露码）。

它们在：

```
D:\license-export\codes_export_20260921.txt
```

`查码.exe` 会自动去找这个文件。如果你把它挪到别的地方，「查码.exe」就只看得到台账状态、看不到明文码了。

**建议**：这个导出文件定期备份到 U 盘或网盘。**它是唯一的明文来源** —— 台账里存的是哈希，哈希不可逆，删了这个文件就再也发不出码了。

---

## 三条铁律

1. **别删 `license_inventory.csv`**。它是唯一记录。删了以后重新生成会从 `001` 开始，和已发出的码**编号撞车**。
2. **别把 `codes_export_*.txt` 连同压缩包一起发给别人**。那是 500 个能直接激活的码。
3. **`license_inventory.csv` 可以进 git，`codes_export_*.txt` 不行**（已经设好 gitignore 了，别手动加回去）。

## 出了问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击 `查码.exe` 闪一下就没了 | 不该发生（设计上会停住） | 用 PowerShell 跑 `.\lookup.exe --wait` 看报错 |
| 显示"明文缺失" | 导出文件被删或挪走 | 找回 `codes_export_*.txt` 放回文件夹 |
| 台账读不到 | CSV 不在 exe 旁边 | 把 exe 和 csv 放同一个文件夹 |
| 用户说码没用 | 先 `verify` 这个码 | 见下 |

**用户说激活不了**，按顺序查：

```
.\license_admin.exe verify <用户报的码>
```

- 显示 `REJECTED` → 码打错了，或者不是你的码。让对方重新复制。
- 显示 `ACCEPTED` 但用户那边失败 → 让对方看界面提示：
  - 「授权已绑定其他设备」→ 这个码在别的电脑用过。需要你发个新码。
  - 「激活码无效」→ 让对方检查有没有多复制空格。
